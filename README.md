# Mini Site - Universo Invocação do Mal

Projeto de site em HTML sobre a franquia de terror *Invocação do Mal* (*The Conjuring*) e os casos paranormais investigados por Ed e Lorraine Warren.

## 📄 Páginas do Site

- **Início (`index.html`)**: Apresentação da franquia, principais filmes lançados e visão geral do tema.
- **Sobre (`sobre.html`)**: História real do casal Warren, detalhes sobre o Museu do Oculto, curiosidades dos bastidores e trailer oficial.
- **Contato (`contato.html`)**: Formulário para envio de dúvidas, sugestões e relatos de fenômenos sobrenaturais.
